## Обоснование выбора коллекций (ИИ-вариант)
* **Map (`HashMap<SampleStatus, Integer>`)**: выбран для подсчёта количества наблюдений по каждому статусу за время $O(1)$ по ключу-перечислению.
* **Set (`HashSet<String>`)**: выбран для сбора уникальных источников данных, так как автоматически исключает дубликаты за $O(1)$ и не требует сохранения порядка.
* **List (`ArrayList<DataSample>`)**: выбран для создания независимой копии списка и последующей сортировки с помощью безопасного `Comparator` без изменения исходных данных.
